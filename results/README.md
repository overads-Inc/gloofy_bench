# results/

Published, versioned evaluation results.

This directory will hold the results files behind the public leaderboard:
one file per (model, benchmark version) run, produced by the harness,
including the frontier-model baselines and including results where gloofy
loses.

Nothing is scored yet, so this directory is empty apart from this README.

Convention: files matching `*.local.*` are gitignored, for private scratch
runs that are not published results.

Status: skeleton. No results exist yet.
