# chat

Open marketing QA.

Open-ended marketing questions and conversations, evaluating whether a
model answers in a consistent, numerate, direct voice: correct on marketing
fundamentals, honest about uncertainty, and free of filler.

## Planned item format

- **Input:** a marketing question or short conversation, possibly with
  supporting context.
- **Expected output:** a free-form answer.
- **Scoring:** rubric-based grading (in the spirit of HealthBench-style
  rubric criteria): factual correctness, numeracy, actionability, and
  absence of confident fabrication.

## Status

Skeleton. No test items exist yet. The rubric and test set will be added
and frozen before any model is scored.
